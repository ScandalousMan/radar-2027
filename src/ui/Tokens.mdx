# Tokens de design

Source unique : `src/ui/tokens.css`. Les noms et familles ci-dessous sont lus dans ce fichier ;
les valeurs sont calculées au rendu dans les deux apparences (clair et sombre). Aucune autre
valeur de style n'est autorisée dans `src/app` et `src/ui` (règle de lint).

Les couleurs sont **sémantiques** (rôle, pas teinte). L'accent est un sarcelle, hors des
couleurs emblématiques des partis. Les contrastes des couples texte/fond sont vérifiés par
`src/ui/tokens.test.ts` (4,5:1 pour le texte, 3:1 pour le focus).
